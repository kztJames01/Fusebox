# fusebox site

One-page site for the local execution gateway and interactive CLI. It is not part of the `fusebox` npm package.

## Preview

From this directory:

```bash
npm install
npm run dev
```

Open the URL Vite prints (it binds to `127.0.0.1`).

## Production build

```bash
npm run build
npm run preview
```

Output goes to `frontend/dist`, which is gitignored.
